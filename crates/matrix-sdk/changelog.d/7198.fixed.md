A redaction of an in-thread event now reaches its thread's cache, even when that
cache isn't loaded, or the event arrived in the same sync. It used to go to
whichever loaded thread cache came first, and a reply redacted in the sync it
arrived in got its content back. The latest event bundled with a thread root no
longer overwrites a stored copy of it, unless that copy couldn't be decrypted or
has a capped timestamp, and never overwrites a redacted one. Clearing the event
cache now forgets the reply counts of all the threads, not only the loaded ones.
Back-paginating a thread now stops once its root is loaded with no gap after it,
instead of walking the leftover chunks and gaps from before the root.
